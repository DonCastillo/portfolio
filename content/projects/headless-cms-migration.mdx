summary: Led the move of client Hugo sites from Forestry to Directus before Forestry shut down, turning Markdown pages into database content that builds back into each site.
problem: >-
  Client websites were Hugo static sites edited through Forestry.io, which
  announced it would end support and shut down in March 2023. Every site
  needed a new CMS before then, without losing content or changing how the
  sites were built and deployed.
solution: >-
  A move to Directus as a headless CMS: existing Markdown pages became
  database rows, and each site's build was changed to generate its pages
  from that content.
results:
  - Client sites moved off Forestry before it shut down.
  - Site content now lives in one CMS database instead of Markdown files spread across repos.
  - Each site still builds as a static Hugo site, so hosting and deployment stayed the same.

  - Changed each site's build so Hugo pulls content from Directus and generates a Markdown file for each row.
