summary: An Android app of two memory games, Arrange the Sequence and Reveal and Match, built with Framework7 and Cordova, with levels that get harder as you go.
problem: >-
  The assignment was to design and build a first mobile app: a fully working
  Android app, with an interface built from Framework7 components, that takes
  user input and changes what's on screen in response.
solution: >-
  Vivid, a collection of quick memory games for when you're bored. In Arrange
  the Sequence you memorize a row of items, then drag them back into order
  before time runs out. In Reveal and Match you flip cards to find the pairs.
  Both get harder level by level.

highlights:
  - Designed the user flow and every screen as a prototype first, from the game picker to the level-complete and level-failed screens, then built the app to match.
  - Built two games in Framework7 with JavaScript and jQuery, with drag-to-reorder in Arrange the Sequence (SortableJS) and flipping cards in Reveal and Match (jQuery Flip).
  - Scaled the difficulty level by level, so Arrange the Sequence grows from 3 items to 15, with a longer countdown at each step.
  - Packaged it with Cordova as an installable Android APK, alongside a browser build.
