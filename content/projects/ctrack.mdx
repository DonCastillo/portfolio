problem: >-
  Software teams track bugs, features and tasks in tools like Jira and Trello.
  The course project was to build a simpler version from scratch as a team,
  working in agile sprints and applying good engineering practice along the way:
  testing, code review, style rules and documentation.
solution: >-
  C-Track, a client–server issue tracker. A REST API stores users, issues and
  comments, and a console client lets people create, edit, comment on and close
  issues. Issues can also be browsed in a web browser, filtered by status, type
  or ID range.
