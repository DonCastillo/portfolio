highlights:
  - Made each project a typed case study, with MDX files validated by a Velite schema so a missing or invalid field fails the build instead of shipping a broken page.
  - Built an image pipeline with Sharp that converts screenshots to WebP, sizes them by type (phone, tablet, desktop) and fails the build on any image over 250 KB.
  - Built the gallery carousel with CSS scroll-snap instead of a carousel library, a lightbox that loads only when opened, and one scroll-tracking hook shared by the sidebar and the table of contents.
  - Kept it accessible, with a skip link, keyboard-reachable navigation and gallery, reduced-motion support, and every text colour at 4.5:1 contrast or better.
  - Deployed as a static export to Netlify, with GitHub Actions running lint, format, type and build checks on every push, Netlify Forms for contact, and analytics only in production.
