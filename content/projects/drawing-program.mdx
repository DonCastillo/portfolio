summary: A simple, intuitive drawing app in Processing, with a palette of colours and brushes, keyboard controls for size and opacity, and colour randomizing and mirror modes.
problem: >-
  The first project of the course was to build a drawing program in Processing:
  one that's simple to pick up, but gives the person drawing real control over
  colour, brush and stroke.
solution: >-
  A drawing app with a palette down the left side for colours and brushes, arrow
  keys to change the brush size and opacity as you draw, a preview of the
  current brush, and shortcuts to randomize colour, mirror strokes, clear the
  canvas and save the drawing as a PNG.

highlights:
  - Sketched the interface on paper first, then built a 16-colour palette and five brushes (regular, air, arrow, circle and square) along the left edge of the canvas.
  - Mapped the arrow keys to brush size and opacity so both can change mid-stroke, with a live preview of the current brush in the corner.
  - Added a colour randomizer that changes the colour as you draw, a mirror mode that draws a reflected copy of every stroke, and shortcuts to clear the canvas or save it as a PNG.
  - Organized the code around Brush and Button classes, laying the palette out in a loop rather than placing each button by hand.
